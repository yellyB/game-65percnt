# 챕터별 상세 씬 아웃라인 (분량 채우기 기획)

> 목표 90~120분. 현재 초안(~20-30분)을 **"여러 장면화 + 디브리핑 + 현실 관계 아크"** 로 심화.
> 각 씬: 목적/감정 · 채울 내용 · 양념(탐색/미니/퍼즐) · 복선. `✅초안` = 이미 있음 / `➕추가` = 새로 써야.
> 집필 기준은 `CHARACTERS.md`(성격·아이러니·각성 곡선·복선 맵).

---

## 챕터 0 · 프롤로그 (~10분)
1. `✅초안` 축제 도착·케미 (솜사탕) + 외모 조건부 씨앗
2. `✅초안` 집착 장면(아는 오빠) + 여주 미화
3. `➕추가` **일상 티키타카 1~2씬** — 둘의 케미를 더 (좋아 보이게), 은근한 통제 하나 더 심기
4. `✅초안` 부스 허브(고양이·인형뽑기) → 사랑 측정 부스
5. `✅초안` 기계 설명 + 확신 독백
- **감정**: 달달한데 플레이어만 오싹. 복선 2~3개 심기.

## 챕터 1 · 성별반전 (~20분)
1. `✅초안` 자각 + 거울 탐색
2. `✅초안` 외형 선택
3. `➕추가` **데이트 여러 장면화** (현재 탐색 1개 → 3~4 실제 장면): 낯섦 → 적응 → 즐거움 → 남주의 조건부 균열
4. `✅초안` 휴대폰 패턴 잠금(감시 정황)
5. `✅초안` 밤 친밀함 갈등 ("여자인 모습이 좋았어")
6. `➕추가` **디브리핑 심화** — 테스트 후 둘이 대화. 여기서 **현실 관계**가 한 겹 드러남 (남주 조건부 재확인, 여주 미화)
- **감정**: "사랑은 껍데기(성별)에 얼마나 매여 있나". 각성 0%.

## 챕터 2 · 강아지 (~15분)
1. `✅초안` 자각(무릎 시점) + 간식 받아먹기
2. `➕추가` **교감 성장 3단계 장면화**: 소통 불가 답답함 → 사소한 교감 → 깊은 유대 (각 장면 + 독백)
3. `✅초안` "의존적일 때 가장 사랑" + 안정감 미화
4. `✅초안` 사랑 논쟁 선택 + 디브리핑
5. `➕추가` **디브리핑에서 현실 균열 암시** (강아지처럼 순종하길 바라는 그의 무의식)
- **감정**: "자유 없는 사랑도 사랑인가". 각성 0%.

## 챕터 3 · 부녀 (~35~40분) — 최대 심화
1. `✅초안` 부녀 자각 + 거부감
2. `✅초안` 집 탐색(통제 기록·가족사진, 애매하게)
3. `✅초안` 경계 무시 소유 + 여주 첫 애매한 균열
4. `✅초안` 체포(함정)
5. `➕추가` **감옥 3년을 시간 흐름으로 장면화** (현재 요약 → 여러 면회 장면): 헌신 → 반복 → 지침 → 비난. 각 면회마다 남주의 집착↑, 여주 미화↓
6. `✅초안` 감옥 키패드 비번(진실 녹음)
7. `✅초안` 감옥 집착 + 여주 첫 진짜 균열
8. `✅초안` 3년 후 비난 선택
9. `➕추가` **출소~재회 사이 장면화**: 여주의 지침·새 사람·죄책감을 실제 장면으로
10. `✅초안` 공터 급발진 + 복선 회수 + 몸싸움 연타(실패=배드엔딩)
11. `✅초안` 사망 + 각성 씨앗
- **감정**: 통제적 사랑의 파국. 각성: 균열 → 공포 자각.

## 챕터 4 · 결과 & 엔딩 (~10분)
1. `✅초안` 현실 복귀 + 남주 무자각 / 여주 각성 payoff
2. `✅초안` 65% 결과
3. `➕추가` **엔딩 직전 정적 씬** — 서로를 바라보는, 밑바닥을 본 두 사람의 침묵을 더 길게
4. `✅초안` 진엔딩 (정떨어짐·헤어짐)
- **감정**: 숫자의 공허 + 완전 각성 + 씁쓸한 여운.

---

## 분량 채우기 핵심 (요약)
- **여러 장면화**: 데이트·교감·감옥 3년·출소~재회 = "요약 한 줄"을 실제 여러 장면으로. (분량의 절반)
- **디브리핑 인터루드**: 매 테스트 후 현실 관계를 한 겹씩. (현실 아크의 척추)
- **독백 강화**: 각 장면마다 여주 1인칭 미화/균열.
- **현실 관계 아크**: 프롤로그(달달) → 테1·2 디브리핑(미세 균열 축적) → 테3(파국) → 엔딩(정떨어짐). 테스트와 병렬로 진행.

## 작업 순서
`➕추가` 씬들을 챕터 순서대로 상세 집필 → 챕터마다 커밋. (지금 `✅초안`은 유지·다듬기)
