# 챕터별 상세 씬 아웃라인 (분량 채우기 기획)

> 목표 90~120분. 현재 초안(~20-30분)을 **"여러 장면화 + 디브리핑 + 커플 감정선"** 으로 심화.
> 각 씬: 목적/감정 · 채울 내용 · 양념(탐색/미니/퍼즐). `✅초안` = 이미 있음 / `➕추가` = 새로 써야.
> **톤 = A (따뜻·가벼움).** 남주는 다정한 평범남. 어두운 전개는 전부 **기계 시뮬레이션의 연출**. 집필 기준은 `CHARACTERS.md`.

---

## 챕터 0 · 프롤로그 (~10분)
1. `✅초안` 축제 도착·케미 (솜사탕)
2. `✅초안` 알콩달콩 장면 (아는 오빠 → 가벼운 질투도 귀엽게)
3. `➕추가` **일상 티키타카 1~2씬** — 둘의 케미를 더 (진짜 좋아 보이게)
4. `✅초안` 부스 허브(고양이·인형뽑기) → 사랑 측정 부스
5. `✅초안` 기계 설명 + 기대 독백
- **감정**: 달달·설렘. "이 테스트 재밌겠다."

## 챕터 1 · 성별반전 (~20분)
1. `✅초안` 자각 + 거울 탐색
2. `✅초안` 외형 선택
3. `✅초안` **데이트 여러 장면화**: 낯섦 → 적응 → 즐거움 (남주 어색해하다 "그래도 너잖아")
4. `✅초안` 휴대폰 패턴 잠금(연출용 소소한 방탈출)
5. `✅초안` 밤 친밀함 갈등 (바뀐 모습에 어색해하는 정도, 악의 아님)
6. `➕추가` **디브리핑 심화** — 테스트 후 둘이 대화. "방금 좀 이상했지?" 하고 웃어넘기는 따뜻함
- **감정**: "사랑이 껍데기(성별)에 얼마나 매여 있나"를 가볍게 던지기. 무겁지 않게.

## 챕터 2 · 강아지 (~15분)
1. `✅초안` 자각(무릎 시점) + 간식 받아먹기
2. `✅초안` **교감 성장 3단계 장면화**: 소통 불가 답답함 → 첫 교감 → 깊은 유대 (각 장면 + 독백)
3. `✅초안` "말 안 통해도 곁에 있어 편안" + 따뜻한 유대
4. `✅초안` 사랑 논쟁 선택 + 디브리핑
5. `➕추가` **디브리핑 소소한 대화** (남주가 정성껏 돌본 게 은근 감동이었단 여주 독백)
- **감정**: "말 없이도 통하는 사랑". 따뜻.

## 챕터 3 · 부녀 (~35~40분) — 최대 심화 (전부 시뮬 연출)
1. `✅초안` 부녀 자각 + 어색함
2. `✅초안` 집 탐색(가족사진 등, 시뮬이 만든 설정)
3. `✅초안` 낯선 관계에 서투른 남주 + 여주 당황
4. `✅초안` 체포(시뮬의 극적 전개)
5. `➕추가` **감옥 3년을 시간 흐름으로 장면화** (여러 면회 장면): 헌신 → 반복 → 지침. 시뮬이 감정을 몰아붙이는 압박감
6. `✅초안` 감옥 키패드 비번(연출용 퍼즐)
7. `✅초안` 감옥 면회 + 여주 소진 (남주 탓 아니라 상황 탓)
8. `✅초안` 3년 후 선택
9. `➕추가` **출소~재회 사이 장면화**: 여주의 지침·복잡한 마음을 실제 장면으로 (시뮬 속)
10. `✅초안` 공터 급발진 + 몸싸움 연타(실패=배드엔딩) — **시뮬의 파국적 연출**
11. `✅초안` 사망 — 시뮬 종료, "이건 가짜야" 자각의 씨앗
- **감정**: 시뮬이 만든 극한 상황의 소진. 남주의 본색이 아니라 **기계 연출**임을 놓치지 말 것.

## 챕터 4 · 결과 & 엔딩 (~10분)
1. `✅초안` 현실 복귀 + 둘 다 멍한 상태
2. `✅초안` 65% 결과
3. `➕추가` **엔딩 직전 정적 씬** — 너무 많은 걸 함께 봐버린 두 사람의 어색한 침묵을 조금 더 길게
4. `✅초안` 진엔딩 (서먹함·미묘한 온도차)
- **감정**: 숫자의 공허 + 미묘한 서먹함 + 씁쓸하고 잔잔한 여운. (정떨어짐/폭로 아님)

---

## 분량 채우기 핵심 (요약)
- **여러 장면화**: 데이트·교감·감옥 3년·출소~재회 = "요약 한 줄"을 실제 여러 장면으로. (분량의 절반)
- **디브리핑 인터루드**: 매 테스트 후 둘이 웃으며 나누는 대화 → 커플 케미를 두텁게.
- **독백 강화**: 각 장면마다 여주 1인칭 애정·당황·따뜻함.
- **감정선**: 프롤로그(달달) → 시뮬1·2 디브리핑(케미 확인) → 시뮬3(시뮬이 만든 소진) → 엔딩(미묘한 서먹함). 테스트와 병렬.

## 작업 순서
`➕추가` 씬들을 챕터 순서대로 상세 집필 → 챕터마다 커밋. (지금 `✅초안`은 유지·다듬기)
