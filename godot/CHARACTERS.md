# 캐릭터 바이블 & 집필 지침 (디테일 기획)

> 원칙: **이름 없음** (여주=나·1인칭 / 남주=남자친구). **백스토리는 암시 수준** (사귄 지 5개월, 콩깍지 끝물).
> 상세 대사는 이 문서의 성격·말투·아이러니 규칙·각성 곡선을 기준으로 쓴다.

---

## 1. 남주 (남자친구)
**표면**: 다정하고 표현 잘 함. 자상해 보이고, 늘 챙겨줌. "좋은 남자"로 보임.
**이면(핵심)**: 보수적 · **소유욕 · 통제**. 사랑을 *"내 것을 지키고 소유하는 것"* 으로 여김. 경계 인식이 약함.
**핵심 심리 한 줄**: **상대가 '내 것'이고 '나에게 의존적'일 때 가장 사랑한다.** 형태(성별·상황)가 바뀌면 사랑이 흔들린다.

**말투**: 다정한 반말 + 애칭("오구~"). 은근 **지시형**("넌 나만 봐", "~해"). 질투 시 **웃음기 사라짐**. 상투어: *"사랑하니까 그래."*

**각 테스트에서의 발현** (같은 본성이 형태만 바꿔 반복):
| 테스트 | 남주의 사랑 = |
|---|---|
| 성별반전 | 외형(여성)에 조건부 → 관계 거부 |
| 강아지 | 의존적일 때 = 최고의 사랑 |
| 부녀 | 관계·경계 무시하는 소유 |
| 감옥/재회 | 집착 → 급발진 → 파국 |

## 2. 여주 (나 · 1인칭)
**표면**: 밝고 현실적. **관찰형**(사소한 걸 잘 봄).
**심리**: 사랑에 빠져 있고, **남주의 통제를 로맨스로 미화**한다. **초반엔 의심하지 않음.**
**말투**: 1인칭 **독백 풍부**. 밝은 반말. 자기 위안("괜찮아, 사랑하니까").
**아크**: 맹목적 미화 → 미세 균열 → (후반) 완전 각성("내가 그의 것일 때만 사랑받았다").

## 3. 관계 현재 상태
- 사귄 지 5개월, 콩깍지 끝물. **겉은 달달, 속은 아슬아슬** — 근데 그 아슬함은 **플레이어만 감지**(여주는 미화).

## 4. ⚠️ 집필 규칙 — 극적 아이러니 (가장 중요)
- **남주 행동/대사는 객관적으로, 살짝 과하게** 보여준다 (통제·집착이 드러나게).
- **여주 나레이션·독백은 그걸 미화**한다 ("이렇게까지 날 원하다니").
- **그 틈에서 플레이어만 "이 남자 이상한데?"** 를 느낀다.
- 초반~중반 여주 독백에 **직접적 의심 금지**. 각성은 후반에만.

## 5. 여주 각성 곡선 (단계 설계)
| 시점 | 여주 상태 |
|---|---|
| 프롤로그 | 100% 미화 (집착=설렘, 통제=아낌) |
| 테스트1 | 미화 유지 (외형 조건부도 이해로 포장) |
| 테스트2 | 미화 (의존=안정감) |
| 테스트3 감옥 | **첫 진짜 균열** ("사랑이었을 텐데, 왜 숨이 막힐까") |
| 테스트3 재회·급발진 | **공포 자각** (하지만 정리 못 함) |
| 결과/엔딩 | **완전 각성** ("내가 그의 것일 때만 사랑받았다") |

## 6. 복선 맵 (심는 곳 → 회수)
| 복선 | 심는 곳 | 회수 |
|---|---|---|
| "넌 나만 봐" (집착) | 프롤로그 | 공터 급발진 "내가 그랬잖아" |
| 외모 조건부 ("이 모습 그대로") | 프롤로그 | 성별반전 거부 "여자인 모습이 좋았어" |
| 폰 감시 (통제) | 챕터1 폰 패턴 | 부녀 수첩(통제 기록) · 감옥 집착 |
| 의존을 사랑함 | 챕터2 강아지 | 전체(통제의 본질) |
| "진짜 얼굴을 끄집어낸다" | 감옥 녹음(퍼즐) | 결과 각성 |
| 여주 미세 균열들 | 챕터1~3 | 결과 완전 각성 |

## 7. 톤 예시 (do / don't)
- 남주 ✅ "누구랑 연락하는지 나는 다 알아야 돼. 사랑하니까." / ❌ 대놓고 악당 대사
- 여주 ✅ "이렇게까지 날 원하는 사람이 또 있을까." (미화) / ❌ "이 사람 좀 무서운데?" (초반 의심 금지)
