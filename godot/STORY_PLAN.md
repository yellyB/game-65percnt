# 스토리 확장 기획서 (본격 장편 · 서사 중심)

> 확정 방향: **1.5~2시간 서사 중심 VN**, **기존 3테스트 심화**, **공동 집필**, **중수위(15세급)**,
> 선택지=게이지→엔딩, 탐색·미니게임=양념, 아트=그레이박스.
> 이 문서는 공동집필용 **뼈대(아웃라인)** — 실제 대사/독백은 `[함께 채움]` 표시된 곳을 채워 넣는다.

## 0. 분량 목표
- 목표 ≈ 90~120분. VN 대사 노드로 대략 **600~900개**(원작 ~120개의 5~7배).
- 5막 구성, 막마다 **탐색 0~1 + 미니게임 0~1 + 독백 다수**를 양념으로.

## 1. 전체 구성 (5막)

### 막 0 · 프롤로그 — 축제 & "진짜 커플" 소개  (~10분)  ⬆신규 심화
> 원작은 바로 기계로 직행. **테스트가 아프려면 먼저 이 커플에 정들어야 함.**
- [함께 채움] 두 사람의 **관계 현재 상태**(사귄 지 5개월, 최근 미묘한 거리감?) 를 축제 대화·행동으로 드러냄
- 부스 허브(양념: 고양이·인형뽑기) → 사랑 측정 부스 진입
- 기계 설명 → 테스트 시작
- **감정 목표**: "이 둘, 좋아 보이는데 뭔가 아슬아슬하다"

### 막 1 · 테스트1 성별반전  (~20분)  ⬆심화
- 자각 → 거울 탐색(양념) → 외형 선택
- [함께 채움] **바뀐 몸으로의 데이트를 여러 장면**으로 (원작 1장면 → 3~5장면): 낯섦→적응→즐거움→미묘한 균열
- [함께 채움] **밤/친밀함 갈등**을 깊게: 남주의 거부, 여주의 상처, 정체성·끌림에 대한 대화
- 테스트 종료 → **디브리핑**(둘이 방금 겪은 걸 이야기 — 여기서 진짜 관계가 드러남)
- **감정 목표**: "사랑은 껍데기(성별)에 얼마나 매여 있나"

### 막 2 · 테스트2 강아지  (~15분)  ⬆심화
- 자각(무릎 시점, 양념 탐색) → 무력감 독백
- [함께 채움] **교감의 성장**을 단계적으로: 소통 불가의 답답함 → 사소한 교감 → 깊은 유대
- 사랑 논쟁 선택 → 디브리핑
- **감정 목표**: "자유·선택 없는 사랑도 사랑인가"

### 막 3 · 테스트3 부녀  (~35~40분)  ⬆⬆최대 심화 (가장 어두움)
- 부녀 자각 → 거부감 → 억지 노력 → 이성적 감정의 순간
- **체포**(함정) → 충격
- [함께 채움] **감옥 3년**을 시간의 흐름으로 (면회 탐색 양념 + 여러 면회 장면): 헌신→지침→비난→폭발
- 출소 → 재회 → 공터(양념 탐색) → 급발진 → **사망**
- **감정 목표**: 시뮬레이션이 현실의 관계를 잠식 / 파국

### 막 4 · 결과 & 에필로그  (~10분)
- 현실 복귀 → **65% 카운트업**(축포)
- [함께 채움] 게이지별 엔딩 A/B/C (냉담·여지·히든)
- **감정 목표**: 숫자의 공허, 씁쓸한 여운

## 2. 심화 기법 (분량을 "늘리기"가 아니라 "깊게")
- **디브리핑 인터루드**: 각 테스트 후 둘이 대화 → 매번 현실 관계가 한 겹씩 드러남 (캐릭터 아크의 핵심)
- **여러 장면화**: 원작 "요약 한 줄"을 실제 장면 여러 개로 (데이트, 면회, 3년 등)
- **독백 강화**: 여주 1인칭 내면 — 원작 톤 유지·확장
- **복선/회수**: 초반 사소한 관계 균열이 후반에 회수되게

## 3. 공동 집필 워크플로
1. **막 단위로** 진행 (막0부터).
2. 내가 **막의 상세 비트 아웃라인**(장면 목록 + 감정 목표 + 양념 배치)을 먼저 제안.
3. 네가 **핵심 감정 장면의 대사·독백을 직접**(목소리) 쓰고, 방향 지정.
4. 내가 **연결 대사·구현**(`Story.gd`/`text/ko.gd`) + 보강 + 검증.
5. 막 끝나면 커밋 → 다음 막.

## 4. 남은 소소한 결정 (개발 중 정해도 됨)
- 언어(한/영/일?), 출시 플랫폼(스팀/itch/모바일, 무료/유료)
- 엔딩 개수·조건 미세조정
- BGM 조달
