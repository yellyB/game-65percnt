# 사랑을 측정합니다 — 기획/설계 문서 (Godot)

원작 시나리오(`../senario.md`)를 Godot 2D 게임으로 구현한 현재 설계 기준.
(웹 버전 초기 기획서 `../implementation-plan.md`는 역사적 참고용 — 아래 "원작 대비 변경"으로 대체됨)

---

## 1. 컨셉
- **한 줄**: 축제의 AI 궁합 테스트 VR에서 커플이 3가지 시뮬레이션(성별반전·강아지·부녀)을 겪고, 현실로 돌아와 "65%"라는 공허한 점수와 씁쓸한 결말을 마주하는 심리 드라마.
- **시점**: 여주 1인칭 (독백 다수).
- **장르**: 2D 비주얼노벨 + 포인트앤클릭 탐색 + 미니게임.
- **톤**: 병맛으로 시작해 점점 어두워지는 반전 드라마.

## 2. 원작(웹 기획서) 대비 변경 — 중요

## 3. 스토리 구조 (7챕터)
1. **프롤로그(축제)** — 걷기 → 부스 허브(고양이 가두기/인형뽑기) → 천막 탐색 → 기계 설명 → 시작
2. **테스트1 · 성별반전** — 자각 → 거울 탐색 → 외형 선택 → 데이트 탐색 → 밤 장면 선택
3. **중간** — 테스트 종료, 계속 여부
4. **테스트2 · 강아지** — 무릎 시점 → 집 탐색(그의 손길 선택·숨은 고양이) → 교감 → 사랑 논쟁 선택
5. **테스트3 · 부녀** — 자각 → 체포(함정) → 감옥 면회 탐색 → 3년후 비난 선택 → 출소·재회 → 공터 탐색 → 급발진 → 사망
6. **결과** — 65% 카운트업(축포)
7. **엔딩** — 게이지로 A/B/C 분기

## 4. 핵심 시스템
### 4-1. 스토리 엔진 (데이터 주도)
- `Story.gd`의 **beat 배열**을 `Main.gd`가 순서 처리. 콘텐츠 추가 = 데이터 추가.
- beat: `title/bg/fade/shake/flash/line/choice/explore/minigame/hub/score/ending`

### 4-2. 탐색
- 핫스팟 조사(단서) → 전부 찾으면 출구 개방.
- **문(`goto`)**으로 방 이동, **줌인(`detail`)**으로 오브젝트 확대 후 내부 핫스팟.
- **숨은 보너스**(hidden): 관찰 보상, 엔딩 C 조건.

### 4-3. 미니게임
- **타이밍/QTE**: 움직이는 마커를 타겟존에서 클릭.
- **인형뽑기(집게)**: 집게 좌우 이동 → 클릭 하강·집기. `speed`/`tolerance` 난이도.
- **검은 고양이 가두기**: 헥사 보드, BFS로 도망치는 고양이를 바리케이드로 가둠. `radius`/`seeds` 난이도. 실패 시 재시도/넘어가기.
- **부스 허브**: 도착 시 여러 부스 중 골라 입장, '나가기'로 진행.
- 결과(성공/실패) → 게이지·플래그·대사 반영.

### 4-4. 게이지 → 엔딩 (payoff)
- 관계 게이지(시작 50). 탐색·선택·미니게임이 가감.
- **판정** (`GameState.compute_ending`):
  - `게이지 < 50` → **A** 냉담(배드)
  - `게이지 ≥ 50` → **B** 여지 있음 (기본 굿엔딩)
  - `게이지 ≥ 60` **그리고 숨은 고양이 둘 다 발견** → **C** 히든(관찰+다정 완벽)
- **주제 보존**: 화면 점수는 항상 65%(미끼), 진짜 결말은 게이지.

#### 게이지 예산 (밸런스)
- **강제(비선택)**: 데이트 3곳 +3
- **선택 5개**(하나씩): 외형(+3/−1) · 밤(+4/−3/−5) · 강아지손길(+5/−3) · 사랑논쟁(+3/−2) · 비난(+2/−1/−4)
- **선택적**: 부스 고양이(승 +3) · 인형뽑기(승 +4/패 −1) · **숨은 고양이 ×2 (+2씩, C 조건)**
- **도달 범위** ≈ 38(냉담) ~ 81(완벽). 대표 결과: 냉담→A(38~45), 다정·비밀X→B(70~77), 다정+비밀둘다→C(74~81).
- 무작위 혼합 분포(근사): **A 17% / B 67% / C 16%** — B가 기본, A/C는 극단.
- 밸런스 수치를 바꾸면 이 표와 `compute_ending` 임계값(B_MIN 50 / C_MIN 60)을 함께 갱신.

### 4-5. 저장 / 번역 / 사운드 / 초상화
- **저장**: 체크포인트(장면 전환·선택·미니게임 끝·탐색 끝·일시정지) 자동 + F5/F9. `user://save.json`.
- **번역**: 모든 텍스트를 `text/ko.gd` 키로. 언어 추가 = 파일 복사 후 값 번역.
- **사운드**: 절차적 효과음(파일 불필요) + BGM 프레임워크(파일 있으면 재생).
- **초상화/아트**: `img/expr/cg` 표기 → 그림 있으면 표시, 없으면 greybox(🎨 이름).
