# 사랑을 측정합니다 — 기획/설계 문서 (Godot)

원작 시나리오(`../senario.md`)를 Godot 2D 게임으로 구현한 현재 설계 기준.
(웹 버전 초기 기획서 `../implementation-plan.md`는 역사적 참고용 — 아래 "원작 대비 변경"으로 대체됨)

## 1. 컨셉
- **한 줄**: 축제의 AI 궁합 테스트 VR에서 커플이 3가지 시뮬레이션(성별반전·강아지·부녀)을 겪고, 현실로 돌아와 "65%"라는 공허한 점수와 씁쓸한 결말을 마주하는 심리 드라마.
- **시점**: 여주 1인칭 (독백 다수).
- **장르**: 2D 비주얼노벨 + 포인트앤클릭 탐색 + 미니게임.
- **톤**: 병맛으로 시작해 점점 어두워지는 반전 드라마.

## 2. 원작(웹 기획서) 대비 변경 — 중요
| 항목 | 원작 웹 기획 | 현재 (Godot) |
|---|---|---|
| 기술 | HTML/CSS/JS 단일 파일 | **Godot 4 · 2D** |
| 엔딩 | 선택 무관 **결말 동일** | **진엔딩 하나(정떨어짐·헤어짐) + 중간 실패 시 배드엔딩** (게이지 없음) |
| 탐색 | 핫스팟 클릭(전부 조사) | **다중 방 이동 + 줌인 상세 + 숨은 보너스** |

| 텍스트 | 코드에 직접 | **키로 분리(번역 구조, en/zh/ja 스텁·한국어 폴백)** |

## 3. 스토리 구조 (7챕터)
1. **프롤로그(축제)** — 걷기 → 부스 허브(고양이 가두기/인형뽑기) → 천막 탐색 → 기계 설명 → 시작
2. **테스트1 · 성별반전** — 자각 → 거울 탐색 → 외형 선택 → 데이트 탐색 → 밤 장면 선택
3. **중간** — 테스트 종료, 계속 여부
4. **테스트2 · 강아지** — 무릎 시점 → 집 탐색(그의 손길 선택·숨은 고양이) → 교감 → 사랑 논쟁 선택
5. **테스트3 · 부녀** — 자각 → 체포(함정) → 감옥 면회 탐색 → 3년후 비난 선택 → 출소·재회 → 공터 탐색 → 급발진 → 사망
6. **결과** — 65% 카운트업(축포)
7. **엔딩** — 게이지로 A/B/C 분기

## 4. 핵심 시스템
### 4-1. 스토리 엔진 (데이터 주도)
- `Story.gd`의 **beat 배열**을 `Main.gd`가 순서 처리. 콘텐츠 추가 = 데이터 추가.
- beat: `title/bg/fade/shake/flash/line/choice/explore/minigame/hub/score/ending`

### 4-2. 탐색
- 핫스팟 조사(단서) → 전부 찾으면 출구 개방.
- **문(`goto`)**으로 방 이동, **줌인(`detail`)**으로 오브젝트 확대 후 내부 핫스팟.
- **숨은 보너스**(hidden): 관찰 보상, 엔딩 C 조건.

### 4-3. 미니게임 / 방탈출 퍼즐 (양념 — 결과는 안 바꿈)
- **타이밍/QTE**: 움직이는 마커를 타겟존에서 클릭.
- **인형뽑기(집게)**: ①좌우 위치 맞추기 → ②잡기 타이밍. 여러 인형 중 목표 인형 뽑기.
- **검은 고양이 가두기**: 헥사 보드, BFS 고양이를 바리케이드로 가둠(탈출로 막히면 즉시 승리). 실패 시 재시도/넘어가기.
- **연타(mash)**: 게이지 채우기. `fail_bad`면 실패 시 **배드엔딩**(예: 공터 몸싸움=사망).
- **강아지**: 간식 받아먹기 · 교감 타이밍.
- **방탈출 — 키패드 비번**(감옥, 벽 낙서→진실) · **패턴 잠금**(챕터1, 남주가 바꾼 폰→감시 정황).
- **부스 허브**: 도착 시 부스들을 다 둘러봐야 '사랑 측정 부스'(진행)가 열림.
- 배치: 축제(고양이·인형뽑기) / 챕터1(폰 패턴) / 챕터2(간식·교감) / 챕터3(키패드·부녀서랍·몸싸움).

### 4-4. 엔딩 (단일 진엔딩 + 배드엔딩)
- **게이지 없음.** 선택지·미니게임·탐색은 전부 **감정 몰입·연출용**(결과를 안 바꿈).
- **진엔딩 하나**: 큰 일을 다 겪고 **서로의 밑바닥을 봐 정떨어짐 → 헤어짐 암시**. (65%는 미끼 숫자)
- **배드엔딩**: 중간 실패 시에만 (예: 공터 몸싸움 연타 실패 = 여주 사망·게임오버·재시작).
- 숨은 고양이 등은 **flavor 발견**(효과 없음, 찾는 재미).

### 4-5. 저장 / 번역 / 사운드 / 초상화
- **저장**: 체크포인트(장면 전환·선택·미니게임 끝·탐색 끝·일시정지) 자동 + F5/F9. `user://save.json` (flags+beat+lang).
- **번역**: 텍스트 전부 키(`text/ko.gd`). en/zh/ja 스텁 존재, 미번역은 한국어 폴백. 설정에서 언어 전환·저장. CJK 폰트는 `assets/fonts/main.ttf`.
- **사운드**: 절차적 효과음(파일 불필요) + BGM 프레임워크(파일 있으면 재생).
- **초상화/아트**: `img/expr/cg` 표기 → 그림 있으면 표시, 없으면 greybox(🎨 이름).
